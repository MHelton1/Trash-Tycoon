# Idle Roundsman guides

The developer guides for the game. `docs/` itself is the game's website (GitHub Pages); these guides are left out of the site. Each guide has a clickable **Contents** list at the top; refresh the lists with `node tools/mdtoc.js` after changing headings. The cross-repository to-do list is `docs/STILL-TO-DO.md` in `MHelton1/roundsman-server`.

| Guide | What is in it |
|---|---|
| [PLAY_STORE.md](PLAY_STORE.md) | Publishing on Google Play: the upload key, the release build, every Play Console answer, version 1.1 ads and the Supporter Pack. |
| [STORE-LISTING.md](STORE-LISTING.md) | The Play listing text (pictures are in `store/`). |
